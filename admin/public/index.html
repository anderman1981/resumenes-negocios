Via 1 — Desde el Admin Dashboard

A

Crear o editar el resumen

Ve a Contenido → click + para nuevo resumen. Llena titulo, libro, autor, descripcion, ideas clave y el contenido Markdown. Guarda.

B

Subir el MP4 generado

Ve a Subir archivos → selecciona destino public/shorts/ → arrastra el .mp4 o haz click para seleccionar. Se subira automaticamente al proyecto.

C

Vincular short al resumen

Ve a Contenido → abre el resumen → en el campo Short (ruta MP4) escribe la ruta relativa: /shorts/crecimiento-dia-X.mp4 → Guardar.

D

Verificar

Ve a Video Shorts para previsualizar. El short aparecera con su titulo y reproductor 9:16. En Dashboard verificas el indicador verde en la columna "Short".

Via 2 — Por Comandos SSH

Paso 1: Conectar al servidor

ssh -i ~/.ssh/id_ed25519_amrosai anderson5@192.168.58.116

cd ~/proyectos-personales/content-sites/googleads/video-pipeline

Paso 2: Generar un short desde un resumen

Pipeline completo: script IA → imagenes → voz (edge-tts) → composicion → subtitulos → MP4 final

# Generar desde cero (pipeline completo ~5-10 min)

yarn produce:summary \

"../../_cola/startups/Dia_0_Resumen_Web_Marco_Estructural-v2.md" \

"crecimiento-dia-0"

# Re-generar solo video (sin IA, usa storyboard existente ~1 min)

yarn produce:summary \

"../../_cola/startups/Dia_0_Resumen_Web_Marco_Estructural-v2.md" \

"crecimiento-dia-0" \

--skip-script --skip-vision --skip-voice --skip-subtitles

Paso 3: Generar TODOS los shorts de una serie

bash scripts/generate-shorts.sh

Ejecuta los 8 shorts de la serie "Crecimiento e Ingresos en Startups" (Dia 0-7) secuencialmente.

Paso 4: Copiar MP4 al sitio web

# Copiar el MP4 renderizado a public/shorts/

cp renders/crecimiento-dia-0/final.mp4 \

../public/shorts/crecimiento-dia-0.mp4

Paso 5: Vincular en el frontmatter

# Agregar campo short al markdown del resumen

short: "/shorts/crecimiento-dia-0.mp4"

O hazlo desde el Admin → Contenido → campo "Short (ruta MP4)".

Comandos individuales

Solo script IA:
yarn script:summary "ruta/resumen.md" "slug"
Solo voz:
yarn voice "slug"
Solo composicion:
yarn compose "slug"
Solo subtitulos:
yarn subtitles "slug"
Diagnostico:
yarn doctor
Verificar modelos:
yarn models:check
