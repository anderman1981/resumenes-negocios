Video Pipeline

El pipeline corre en el servidor AMR (SSH). Usa estos comandos para generar shorts.

# Conectar al servidor

ssh -i ~/.ssh/id_ed25519_amrosai anderson5@192.168.58.116

# Ir al pipeline

cd ~/projects/googleads/video-pipeline

# Re-generar un short (solo compose + render + mux)

yarn produce:summary "../../_cola/startups/Dia_0_Resumen_Web_Marco_Estructural-v2.md" "crecimiento-dia-0" --skip-script --skip-vision --skip-voice --skip-subtitles

# Generar desde cero (incluye script + voice + subtitles)

yarn produce:summary "../../_cola/startups/Dia_0_Resumen_Web_Marco_Estructural-v2.md" "crecimiento-dia-0"
